# Regras do Projeto Conveniência

## Atualização de Versão
Toda vez que você (o assistente de IA) fizer QUALQUER alteração no código deste projeto (seja HTML, CSS, JS ou qualquer outro arquivo), você DEVE obrigatoriamente atualizar a data da versão no arquivo `index.html`.

A versão fica localizada no elemento `div#appVersionDisplay` (geralmente próximo ao rodapé/menu) e segue o formato `vAAAA.MM.DD.vX` (exemplo: `v2026.08.16.v1`).

Sempre garanta que a data exibida corresponda ao dia da alteração atual e que o número final (vX) seja incrementado ou ajustado conforme a versão diária.

**Esta é uma regra estrita exigida pelo usuário e nunca deve ser ignorada.**
